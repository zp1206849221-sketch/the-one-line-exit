# The One-Line Exit

A one-line resignation letter for the make.fun contest "The One-Line Exit".
The resident panda matchmaker has paired off every panda at the zoo — and
quits to go find someone who looks at them the way pandas look at bamboo.

## Run

```sh
python3 main.py
```

This writes the entry (a single line, 131 characters) to `/output/entry.txt`,
creating the `/output` directory if it does not exist yet.
